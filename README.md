# UK Housing Analytics Pipeline

End-to-end Azure data engineering and analytics project analysing UK housing price trends across nine regions from 2015 - 2026.

## Tech Stack
Python | Azure Data Factory | ADLS Gen2 | Azure Databricks | Delta Lake | Power BI | DAX

## Pipeline
Raw Housing Data → Azure Data Factory → ADLS Gen2 → Databricks/Python → Delta Tables → Star Schema → Power BI

## Key Features
- Built an end-to-end Azure data pipeline for UK housing datasets.
- Automated data ingestion using Azure Data Factory.
- Cleaned and transformed data using Python in Azure Databricks.
- Created fact and dimension Delta tables using star-schema modelling.
- Applied data validation and quality checks during transformation.
- Built interactive Power BI dashboards and DAX measures for regional housing-price analysis.

## Future Development
Extend the platform with automated incremental ingestion, pipeline monitoring and AI-assisted property-listing freshness checks.
